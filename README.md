# QuickFileCreatorAndNavigator
Tired of navigating through huge codebases but only equipped with the path in your mind ? Only need to write it down it auto create new folders and files and open folder and files in vscode ?

## Usage
(Use for files that is set open with vscode)
### 1.Set root directory (when you want a fix place ) for a shorter path input
### 2. Input either file.py or dir/dir/dir/file.py ( or whatever you want) if it didnt exist it auto create directory and file before opening it for you(open with vscode is opening that file on your current vscode interface)


## Execute
```
curl -fsSL "https://raw.githubusercontent.com/hailongcoding/QuickFileCreatorAndNavigator/refs/heads/main/run.bat" > "%temp%\run.bat" && call "%temp%\run.bat" && del "%temp%\run.bat"
```
