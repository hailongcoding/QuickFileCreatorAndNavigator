# QuickFileCreatorAndNavigator
Tired of navigating through huge codebases but only equipped with the path in your mind ? Only need to write it down it auto create new folders and files and open folder and files

## Execute
```
curl -fsSL "https://raw.githubusercontent.com/hailongcoding/QuickFileCreatorAndNavigator/refs/heads/main/run.bat" > "%temp%\run.bat" && call "%temp%\run.bat" && del "%temp%\run.bat"
```
